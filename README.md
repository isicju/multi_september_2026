2. Напишите решение используя synchronized/reentrantlock/readwritelock/stampedlock

4. Сделайте решение шардированным. Эта часть очень важна, постарайтесь её сделать.

При переводе денег если один из accountId не существует то возвращайте ERROR_ACCOUNT_NOT_FOUND, аналогично
