# 1. Первая часть

**"Сделать шардированный переод денег"**

1. После третьей домашки у вас есть написанный BankTransfer,  теперь
вам нужно его улучшить и зашардировать структуру хранения денег
2. Напишите JCStress тест который проверит что ваше решение потокобезопасно.

# 2. Вторая часть

**"Поменять BankTransfer с блокирующего подхода на неблокирующий"**

Вместо блокирующего подхода используйте неблокирующий. Скорее всего
решение полностью менять весь ledger - очень плохая  затея, поэтому
перепишите структуру хранения переводов: храните все исходные значения
в мапе а все переводы в связанном список(ах). (Это решение тоже полная лажа но хороша для
практики)
